# Surface maps

CC0 assets from Poly Haven, downloaded at 1K. Diffuse maps are converted to neutral luminance in the renderer so the user's selected color remains editable. Normal and roughness maps are used together. Leather UVs sample the region without the upholstery seam.

- Rough Linen — Rico Cilliers / colormass: https://polyhaven.com/a/rough_linen
- Fabric Leather 02 — Rob Tuytel: https://polyhaven.com/a/fabric_leather_02
- License: https://polyhaven.com/license

Kraft fibers are generated in the renderer. Soft touch uses a smooth dielectric surface with broad diffuse highlights. Acetate retains its transmission settings.
